Biggest weakness: the pipeline can receive enough research, produce a weak first draft, then lack the information needed to repair it properly. Conflicting instructions and uneven grounding compound the problem.

Code behavior below is confirmed by inspection. Article effects are risks inferred from that behavior, not reproduced failures from a fresh generation run. Passing tests verify selected mechanics; they do not prove editorial quality.

01 / The writer’s desk

What reaches the writer

The writer does not browse or read original webpages. It receives four assembled inputs.

Article Brief

Reader, outcome, spine, must-name items, failure condition, and operator-supplied material.

Writing packet

Selected claims copied verbatim, confidence, dates, venue notes, and linked source caveats and conflicts.

Section plan

Headings, purposes, claim IDs, and word budgets. An invalid outline can degrade to opening and takeaway guidance.

Writing instructions

Questurian voice, article form, topic modules, audience, conventions, house rules, SEO rules, and anti-AI rules.

Selection controls what reaches compose. The full research dossier remains available to groundedness. The packet preserves factual text without another AI summarization step—a useful safeguard.

02 / Execution

How it actually writes

  1. Outline

    A model plans sections. Invalid plans can degrade to opening/takeaway guidance; writing continues.

  2. Compose the whole article

    One JSON response, with a 6,144-token output allowance. No separate section-writing calls. The model comes from routing configuration; creativity maps to temperature.

  3. Conditional style cleanup

    An additional anti-AI rewrite runs if the prose fails style validation.

  4. Grounding

    A model checks the draft against research records.

  5. Quality audit

    A model scores the draft, supplemented by deterministic checks.

  6. Repair, if permitted

    At most one automatic attempt, subject to budget. Repair returns the entire article; grounding and audit run again.

  7. Settle and save

    Keep-best logic selects a draft. Finalize saves it and preserves the seed as final headline. needs_revision remains advisory.

03 / Ranked findings

Where the writer can go wrong

01High

First-hand material is invisible to grounding

Confirmed: compose receives brief.material; grounding receives only evidence.records_text, normalized from the work order and evidence package.

Example: the operator records “I waited 45 minutes” only in the brief. The writer legitimately uses it. The checker cannot see its origin and may label it unsupported; repair is instructed to delete unsupported assertions.

This is an input mismatch. Whether deletion happens depends on the model response.

Fix: give grounding the supplied material and explicit rules distinguishing first-hand testimony from web evidence.

Source: grounding inputs

02High

Malformed grounding output can become a clean pass

Confirmed: the grounding call has no response schema. The sanitizer computes success from the absence of high-severity claims.

Consequently, {} becomes checked: true, grounded: true. Even grounded: false without a valid high-severity claim list becomes grounded. Invalid severity values become low.

This can present an unusable checker response as verified support.

Fix: require valid checker fields. Malformed output should become unchecked, never passed.

Source: _sanitize_groundedness

03High

Repair cannot recover selected facts omitted by compose

Confirmed: repair receives the previous draft, revisions, and a compact scope/caveat lock. It does not receive the selected factual statements, and explicitly forbids adding factual material—even researched material.

Example: the packet contains three useful restaurant comparisons. The first draft names restaurants without comparing them. Audit requests decision support. Repair must improve the comparison without access or permission to use the omitted facts.

Likely effects: repetition, vague judgment, or an unresolved revision.

Fix: give repair access to frozen selected facts, with permission to use those facts only. Preserve the editorial selection boundary.

Source: repair prompt

04High

Active instructions contradict each other

Confirmed: compose receives conflicting directions in the same prompt.

InstructionConflicting instruction
Gaps belong in internal metadata onlyHouse rules: “Missing support remains a visible gap”
Preserve supported uncertaintyVoice: “It never hedges”
Selected facts are optional materialHouse rules retain research-question completion language
Brief defines the current articleHouse rules retain old commission, requirements, and exclusions language

Likely effects: research-process paragraphs, stripped qualifications, and checklist prose. Precedence language helps, but models still receive contradictory directions.

Fix: remove prompt contradictions before adding more rules.

Source: house rules · Source: voice

05Medium

Extra style rewrite lacks original evidence context

Confirmed: anti-AI enforcement remains active after compose and repair, despite ADR 0032 saying it was dropped. An existing test explicitly acknowledges this discrepancy.

Cleanup receives the article plus style errors, not the packet and brief. It can reshape carefully qualified language without seeing why the qualification mattered. Grounding afterward helps, but remains model judgment.

This also means “compose” can cost more than one generation call.

Source: cleanup implementation

06Medium

Section-scoped repair is not an enforced edit boundary

Confirmed: repair regenerates the full article. Code measures changed sections but does not reject or restore changes outside the requested scope. Keep-best can retain broad rewrites when audit scores favor them.

A request to fix one paragraph can therefore alter good prose elsewhere.

Fix: enforce scope by applying section replacements, rather than trusting a whole-article response.

Source: repair handling

07Medium

Fixed structure can flatten different article forms

Confirmed: every article must contain at least three H2 headings, a 40–60-word direct answer, and closing takeaways. Compose must follow outline headings in order.

Useful for service guides; potentially awkward for profiles, essays, or interviews. Combined with a weak outline, this encourages template-shaped writing despite different briefs.

Fix: make structural obligations depend on the article form.

Source: compose rules

Evidence boundary

Grounded does not mean true

Grounding checks consistency with supplied research, not whether the research itself is true. Incorrect incoming facts can survive perfectly. It also exempts general background and judgment, so “every factual statement traces to a claim” is stricter than actual enforcement.

04 / Recommended sequence

Fix the mechanisms before changing models

  1. Validate grounding responses. Prevent malformed results from passing.
  2. Supply first-hand material to grounding. Keep valid personal details visible to the checker.
  3. Remove contradictory instructions. Establish one consistent writing contract.
  4. Make repair evidence-aware. Allow recovery of omitted selected facts.
  5. Enforce section edits. Protect prose outside the requested repair.
