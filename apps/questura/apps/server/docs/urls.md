# API Routes Documentation

Complete list of all backend API routes in this application.

**Base URL (Development):** `http://localhost:4000`

---

## Authentication Routes

### Visitor Authentication

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/visitor-auth/sign-in/email` | Sign in with email and password |
| `POST` | `/api/visitor-auth/sign-up/email` | Create a Visitor account |
| `POST` | `/api/visitor-auth/sign-out` | End the Visitor session |
| `GET` | `/api/me` | Get the normalized Current principal |

### Google OAuth

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/visitor-auth/sign-in/social` | Start Google OAuth |
| `GET` | `/api/visitor-auth/callback/google` | Google OAuth callback |

### Password Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/visitor-auth/change-password` | Change the current Visitor password |
| `POST` | `/api/visitor-auth/request-password-reset` | Send a password-reset link |
| `POST` | `/api/visitor-auth/reset-password` | Reset a password using the emailed token |
| `POST` | `/api/account/set-password` | Add a password to an OAuth-only Visitor account through the Questura server adapter |

### Email Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/visitor-auth/change-email` | Send an email-change verification link |
| `GET` | `/api/visitor-auth/verify-email` | Verify a Visitor email token |
| `POST` | `/api/visitor-auth/send-verification-email` | Resend a Visitor email-verification link |

## Payment Routes

### Subscription Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/payments/create-checkout-session` | Create Stripe checkout session for subscription (requires auth) |
| `POST` | `/api/payments/create-portal-session` | Create Stripe Customer Portal session for billing management (requires auth) |
| `GET` | `/api/payments/subscription-details` | Get user's subscription details from Stripe (requires auth) |
| `POST` | `/api/payments/cancel-subscription` | Cancel user's subscription at period end (requires auth) |
| `POST` | `/api/payments/reactivate-subscription` | Reactivate cancelled subscription (requires auth) |
| `POST` | `/api/payments/webhooks/stripe` | Stripe webhook endpoint for subscription events (no auth required) |

## Route Authentication Requirements

### Public Routes (No Authentication Required)
- `POST /api/visitor-auth/sign-in/email`
- `POST /api/visitor-auth/sign-up/email`
- `POST /api/visitor-auth/sign-in/social`
- `GET /api/visitor-auth/callback/google`
- `POST /api/visitor-auth/request-password-reset`
- `POST /api/visitor-auth/reset-password`
- `POST /api/payments/webhooks/stripe` (Stripe signature verification required)

### Authenticated Routes
Visitor routes use the Better Auth `questura_visitor` session cookie. Payload admin and editorial routes use the Payload `payload-token` staff cookie.

---

## Request/Response Formats

### Authentication Header
```
Cookie: questura_visitor.session_token=<session_token>
```

### Common Response Format
```json
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {}
}
```

### Error Response Format
```json
{
  "success": false,
  "error": "Error message",
  "details": "Additional error details"
}
```

## CORS Configuration

All API routes support CORS for requests from configured frontend origins:
- Configured via `APP_CONFIG.CORS_ORIGINS` in `src/shared/config/index.ts`
- Development default: `http://localhost:3000`
- All routes include `OPTIONS` method for CORS preflight

---

## Notes

- Visitor auth routes use credentialed CORS handling and `OPTIONS` preflight support
- Visitor sessions are managed by Better Auth; Staff sessions are managed by Payload
- Google OAuth flow uses state parameter for security (CSRF protection)
- Subscription webhooks are secured via Stripe signature verification
- Rate limiting is implemented for Google account linking (5 attempts per hour)
