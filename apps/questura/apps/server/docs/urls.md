# API Routes Documentation

Complete list of all backend API routes in this application.

**Base URL (Development):** `http://localhost:4000`

---

## Authentication Routes

### User Authentication

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/login` | Login with email and password |
| `POST` | `/api/auth/signup` | Create new user account with email/password |
| `POST` | `/api/auth/logout` | Logout current user (clears auth cookie) |
| `POST` | `/api/auth/verify-password` | Verify user's current password (requires auth) |

### Google OAuth

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/auth/google/authorize` | Initiate Google OAuth flow (redirects to Google) |
| `GET` | `/api/auth/google/callback` | Google OAuth callback handler (processes OAuth response) |

### Password Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/request-password-change` | Request password change verification code (requires auth) |
| `POST` | `/api/auth/confirm-password-change` | Confirm password change with verification code (requires auth) |
| `POST` | `/api/auth/change-password` | Change password directly for authenticated user (requires auth) |
| `POST` | `/api/auth/forgot-password/request` | Request password reset verification code for forgotten password (no auth required) |
| `POST` | `/api/auth/forgot-password/verify-code` | Verify password reset code is valid without resetting password (no auth required) |
| `POST` | `/api/auth/forgot-password/reset` | Reset password with verification code (no auth required) |

### Email Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/request-email-change` | Request email change verification code (requires auth, requires local password) |
| `POST` | `/api/auth/confirm-email-change` | Confirm email change with verification code (requires auth) |
| `POST` | `/api/auth/confirm-email` | Confirm email with verification code and perform auto-login (no auth required) |
| `POST` | `/api/auth/resend-verification` | Resend verification code to unverified account (no auth required) |

## User Routes

|--------|----------|-------------|
| `GET` | `/api/user/me` | Get authenticated user's profile and subscription data |
| `POST` | `/api/user/check` | Check if user exists by email and return available auth methods |

## Account Management Routes

### Authentication Method Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/account/add-password` | Add password to Google-only account (requires auth) |
| `POST` | `/api/account/remove-password` | Remove password from dual-auth account (requires auth + confirmation) |
| `POST` | `/api/account/link-google` | Initiate Google account linking for password-only account (requires auth) |
| `GET` | `/api/account/link-google` | Alternative GET endpoint for direct Google linking redirect |
| `POST` | `/api/account/unlink-google` | Unlink Google from dual-auth account (requires auth + confirmation) |
| `POST` | `/api/account/can-disconnect` | Check if auth method can be safely disconnected (requires auth) |
| `GET` | `/api/account/can-disconnect?method=google|password` | GET version - check if method can be disconnected |

## Payment Routes

### Subscription Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/payments/create-checkout-session` | Create Stripe checkout session for subscription (requires auth) |
| `POST` | `/api/payments/create-portal-session` | Create Stripe Customer Portal session for billing management (requires auth) |
| `GET` | `/api/payments/subscription-details` | Get user's subscription details from Stripe (requires auth) |
| `POST` | `/api/payments/cancel-subscription` | Cancel user's subscription at period end (requires auth) |
| `POST` | `/api/payments/reactivate-subscription` | Reactivate cancelled subscription (requires auth) |
| `POST` | `/api/payments/webhooks/stripe` | Stripe webhook endpoint for subscription events (no auth required) |

## Route Authentication Requirements

### Public Routes (No Authentication Required)
- `POST /api/auth/login`
- `POST /api/auth/signup`
- `POST /api/user/check`
- `GET /api/auth/google/authorize`
- `GET /api/auth/google/callback`
- `POST /api/auth/forgot-password/request` (For users who forgot their password)
- `POST /api/auth/forgot-password/verify-code` (For verifying password reset code)
- `POST /api/auth/forgot-password/reset` (For users resetting password with code)
- `POST /api/payments/webhooks/stripe` (Stripe signature verification required)

### Authenticated Routes (Requires Valid JWT Token)
All other routes require authentication via JWT token in Authorization header or cookie.

## Request/Response Formats

### Authentication Header
```
Authorization: Bearer <jwt_token>
```

### Common Response Format
```json
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {}
}
```

### Error Response Format
```json
{
  "success": false,
  "error": "Error message",
  "details": "Additional error details"
}
```

## CORS Configuration

All API routes support CORS for requests from configured frontend origins:
- Configured via `APP_CONFIG.CORS_ORIGINS` in `src/shared/config/index.ts`
- Development default: `http://localhost:3000`
- All routes include `OPTIONS` method for CORS preflight

---

## Notes

- All routes use centralized CORS handling via `corsResponse()` and `handleCorsOptions()`
- Authentication uses JWT tokens with 7-day expiration
- Password changes and email changes increment `tokenVersion` to invalidate other sessions
- Google OAuth flow uses state parameter for security (CSRF protection)
- Subscription webhooks are secured via Stripe signature verification
- Rate limiting is implemented for Google account linking (5 attempts per hour)
