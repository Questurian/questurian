Before you start

Live Stripe is real money. Nothing below starts a checkout or changes a subscription. The one optional checkout step waits for the owner to say yes, and even then you stop on Stripe's page and don't pay.

Two live members exist (the live DB has 2 active profiles, latest paid_through_at 2026-09-19). Their renewals kept billing in Stripe while the site was parked. Our copy of their membership state is stale until reconcile runs.

Read-only Stripe only: apps/questura/scripts/stripe-live or the Dashboard. Never the Mac's stripe CLI key.

If anything breaks: apps/questura/infra/softprod/rollback.sh reverts to the previous release.

Go live

Resume, then deploy main

Skip this if you already did it for visitor-auth.html.

  1. Resume. On the Linux laptop: 
    bash ~/Projects/questurian/apps/questura/infra/softprod/resume-live.sh
  2. Expect a reconcile run to start right away. questura-reconcile.timer is Persistent=true and missed every night since 2026-08-20, so enabling it runs one now. It runs on the old release with apply on (cap 25), and holds deploy.lock for up to 30 minutes. Wait until it's done before you deploy: 
    systemctl --user status questura-reconcile.service --no-pager
tail -40 ~/questura/reports/reconcile-latest.log
    If deploy.sh says "another Questura deploy is running", this is why.
  3. Deploy: 
    ~/questura/deploy.sh
