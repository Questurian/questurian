Before you start

Live Stripe is real money. Don't start a checkout. Viewing the Membership section on the account page is fine.

Don't flush the live Redis (questura-redis, port 6379). Sessions surviving a Redis loss was already proven on the local Redis.

If anything breaks: apps/questura/infra/softprod/rollback.sh reverts to the previous release.

Go live

Turn the site on and deploy main

  1. Resume the parked services. On the Linux laptop itself: 
    bash ~/Projects/questurian/apps/questura/infra/softprod/resume-live.sh
    From the Mac: ssh linux-laptop 'bash -s' < apps/questura/infra/softprod/resume-live.sh
  2. Deploy the merged work (a5864efb or later): 
    ~/questura/deploy.sh
  3. Open https://www.questurian.com and confirm the page loads.
